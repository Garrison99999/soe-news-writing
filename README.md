# 国企新闻稿写作

一个用于中文国企调研、座谈和合作交流新闻稿的 Agent Skill。把会议资料转化为主线清楚、发言归属准确、工作语言具体的新闻消息，支持起草、修改、审校和稿件比较。

技能标识：`soe-news-writing`。版本：`1.0.0`。许可证：MIT。

## 适用场景

- 调研来访、座谈交流、合作对接、慰问走访和专项调研。
- 将会议笔记中的口头表达提炼为准确的正式工作语言。
- 检查事实状态、人物表态、会议共识及并列层次。
- 比较两篇同类稿件的用词、句式与结构。

正式请示、报告、纪要等应按相应文种要求处理。本技能不代表任何企业、政府部门或平台的官方写作规范。

## 核心方法

1. 用方案核对安排，用会议记录核对实际发生的事，用汇报材料核对业务事实。
2. 先确定新闻主线，再组织参会方分别表态。
3. 确认共同认识后，在双方发言之后作简短总结。
4. 将口头表达提炼为“动作＋对象”，有依据时补充办法、载体和目标。
5. 分清已完成、正在推进、拟开展，以及建议、共识和决定。
6. 改稿读取当前主版本，保留已确认内容，按要求另存。

## 安装

本目录自身即技能包，根目录包含 `SKILL.md`。下载或克隆后，将整个目录放入所用 Agent 支持的技能发现目录，目录名保持为 `soe-news-writing`。不同工具的发现目录和启用方式以其文档为准。

本技能只包含文本指令、参考方法和虚构练习，不包含可执行脚本、网络接口、账号配置或特定电脑路径。`agents/openai.yaml` 为支持该元数据格式的工具提供显示信息，其他工具可使用 `SKILL.md`。

## 使用示例

### 起草

> 使用 $soe-news-writing，阅读我提供的会议方案、汇报材料和笔记，为企业官网起草一篇座谈交流新闻稿。重点突出信息服务合作，按我说明的范围处理数据。

### 先确认思路

> 使用 $soe-news-writing，先核对材料，提交新闻主线、段落安排和待核实事项，等我确认后再起草。

### 修改

> 使用 $soe-news-writing，以指定文件为主版本，按我的标注修改并另存新版。

### 审校与比较

> 使用 $soe-news-writing，检查这篇新闻的事实归属、工作状态、并列层次和语言逻辑，先列问题与修改建议。

> 使用 $soe-news-writing，对比两篇同类新闻的用词和造句，区分可以迁移的表达方法与不能移用的业务事实。

`$soe-news-writing` 是支持此调用形式的工具中的示例写法；也可通过工具的技能选择入口启用。

## 输入与结果

提供材料及其位置，说明发布主体、渠道、报道重点、披露限制和当前主版本。信息已在资料中写清时无需重复填写。

完整材料可用于形成草稿；关键事实不足时先列待确认事项；改稿和审校按用户指定范围处理。没有预设篇幅、段数、固定政治表态或强制 Word 输出。
